세계관 노트 편집과 내보내기

노트를 사이트에서 직접 고치고, 바뀐 부분만 파일로 내보내서 저에게 올리면 제가 저장소에 반영하는 기능이에요. 이미 정해진 부분은 제가 그대로 만들고, 아래 애매한 부분만 골라 주세요. 카드 선택과 함께 글로 적는 칸에 하고 싶은 말을 자유롭게 적어도 돼요. 다 적고 나면 선택 결과 복사를 눌러 대화에 붙여 넣어 주세요.

정해진 흐름
① 편집 모드 켜기→② 글 고치기(내 브라우저에 자동 저장)→③ 변경 내용 내보내기(바뀐 부분만 담은 파일)→④ 파일을 저에게 전달→⑤ 제가 data.js에 반영하고 푸시
핵심식량은 허기로 대체
첨언허기가 높으면 선택지가 줄고 전투·회피가 떨어진다. 핵심으로 ↑ ✕
내보내기 파일: 첨언 1개 떨어진다. 떨어지고 몸 부위가 손상된다.
1. 편집 범위Q1

편집 모드에서 어디까지 고칠 수 있게 할까요?

A글만

  • 핵심·첨언·열린 질문·규칙·이야기 씨앗의 문장을 고치고, 추가하고, 지우기
  • 첨언을 "핵심으로 올리기"
  • 가장 단순하고 안전해요

BA + 제목·이름·상태

  • 글 편집에 더해 제목/이름, 상태(핵심만 · 첨언 있음 · 확정)를 바꾸기
  • "확정"을 직접 눌러 표시할 수 있어요

CB + 새 항목 추가와 삭제

  • 새 줄, 새 사전 항목(도시·마을·신 등)을 만들고 지우기
  • 구조가 바뀌어서 반영할 때 충돌 가능성이 커요
글로 적기 (선택)
2. 수정 내용 전달 방식Q2

내보낸 파일을 저에게 어떻게 줄지예요. 저는 사이트에서 직접 저장소에 쓸 수 없어서 전달 단계가 필요해요.

AGitHub에 파일 올리기

  • 저장소 edits 폴더에 파일을 올리면 (GitHub 웹에서 "Add file")
  • 제가 받아서 반영해요. 길이 제한이 없어요
  • 폰에서도 GitHub 앱/웹으로 가능해요

B텔레그램에 붙여넣기

  • 내보내기 버튼으로 복사한 내용을 텔레그램에 보내요
  • 짧은 수정에 좋아요. 한 번에 약 4,000자까지만 돼요
  • 긴 수정은 나눠 보내야 해요

C이 대화창에 파일/내용 주기

  • 지금처럼 작업 대화창에 붙여 넣거나 파일 경로를 알려 주기
  • 제가 바로 확인하고 질문할 수 있어요
  • 컴퓨터 앞에 있을 때 편해요
글로 적기 (선택)
3. 새 내용과 겹칠 때Q3

텔레그램 인터뷰가 같은 줄을 바꿔 놓은 뒤에 수정 파일이 도착하면 같은 곳이 겹칠 수 있어요.

A내 수정이 우선

  • 겹치면 파일에 담긴 수정으로 덮어써요
  • 인터뷰에서 바뀐 부분이 사라질 수 있어요

B겹치면 보류하고 알려 주기

  • 겹치지 않는 수정은 바로 반영해요
  • 겹친 것만 따로 목록으로 보여 드리고 하나씩 정해 주세요

C인터뷰 내용이 우선

  • 겹친 수정은 반영하지 않고 알려 드려요
  • 최근 결정이 보존돼요
글로 적기 (선택)
4. 꼭 있었으면 하는 편집 기능Q4

제가 이미 넣기로 한 것: 내용 수정·추가·삭제, 자동 저장, 바뀐 곳 표시, 전체/항목별 되돌리기, 첨언→핵심으로 올리기.

5. 내보내기 파일 요구사항Q5

기본은 바뀐 부분만 담은 JSON 파일이에요(항목, 바뀌기 전 글, 바뀐 글). 더 필요한 게 있으면 적어 주세요.
