# testroom — 시안 기록실

고르거나 확인해야 하는 시안을 모아 두는 곳. 목록(`index.html`)은 최신순이고 검색·필터가 된다.
https://kjooy0305.github.io/testroom/

- 새 시안: `mocks/<id>/index.html` 을 만들고 `data.js` 에 한 개 덧붙인다.
- 시안 페이지의 옵션 카드(`.opt`)에서 "이걸로 선택"을 누르면 브라우저에 저장되고 목록에 진행도가 표시된다. 하단의 "선택 결과 복사"로 결과를 대화에 붙여 넣는다.
- 상태: `open` 선택 필요(목록 위) / `done` 선택 완료 / `archive` 보관.
